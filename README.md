# Razorpay Payment Gateway (Frontend Demo)

This project demonstrates **Razorpay Payment Gateway integration using React (Frontend Only)**.  
It is intended **for demo and UI showcase purposes**, not for production use.

---

## 🚀 Features

- Razorpay Checkout integration
- Frontend-only payment flow
- Test mode payments
- Product-based payment UI
- Prefilled user details
- Payment success & failure handling

---

## ⚠️ Important Note

This project is a **frontend demo only**:

- ❌ No backend
- ❌ No order creation API
- ❌ No payment verification
- ❌ Not production-ready

For real payments, **a backend is mandatory**.

---

## 🛠️ Tech Stack

- React
- TypeScript
- Razorpay Checkout SDK
- Tailwind CSS / Shadcn UI (if used)
